## ⚡ Currently Building

> **I like taking difficult ideas and turning them into working systems.**

### ♟️ Searchless Chess Engine
**34M parameter Amortized Planning Transformer · PyTorch**

A neural chess engine designed to predict **action-values directly**, removing the need for traditional Monte Carlo Tree Search during inference.

**Core ideas:** Transformer Architecture · Amortized Planning · Knowledge Distillation · Stockfish 16

🔗 [Explore the project](https://github.com/syedmuntaquakarim/searchless-chess-pytorch)

### 🗣️ Empathetic Digital Concierge
**30.3M parameter DDPM · Audio → 260D ARKit Blendshapes · Unreal Engine 5**

A generative system that transforms speech into emotionally expressive facial motion for **UE5 MetaHumans**.

```text
Audio → Feature Extraction → Diffusion Model → 260D ARKit Blendshapes → UE5 MetaHuman
```

### 🌌 Computational Physics × Graphics
